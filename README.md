# HomeRoleplay SA-MP Client

A private SA-MP launcher for HomeRoleplay server.

## Features
- Video background
- Server connection
- Custom UI design
- Voice chat support

## Getting Started
This is a private Flutter project for HomeRoleplay.

## Installation
1. Clone this repository
2. Run `flutter pub get`
3. Run `flutter run`

## Build App
`
flutter clean
flutter pub get
flutter build apk --release --android-skip-build-dependency-validation
`
